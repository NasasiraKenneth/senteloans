# Senteloans Project Memory

## Project Overview
**Sente Loan** is a comprehensive web application designed specifically for Saccos (Savings and Credit Cooperatives) and credit cooperatives in Uganda. The platform digitizes and streamlines the entire cooperative financial management process, making it easier for these community-based financial institutions to serve their members effectively.

## Development Practices
- **Package Manager**: Always use pnpm instead of npm or yarn for all package installations and management
- **Testing Approach**: Follow Test-Driven Development (TDD) methodology - write unit tests before implementing features
- **Test Coverage**: All major application logic must have corresponding unit tests
- **API-first Development**: Use API-first development approach to design and implement the API
